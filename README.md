# PKsim-Shiny

## Overview

PKsim-Shiny is an educational pharmacokinetic simulation application
based on a linear one-compartment model.


## Intended use

PKsim-Shiny is intended for educational, research, demonstration,
and other non-clinical purposes.
It is not intended for clinical decision-making or patient care.


## Requirements

- R
- RStudio
- shiny
- ggplot2
- markdown
- showtext
- sysfonts
- curl

## How to run

1. Install R and RStudio.
2. Download `app.R`.
3. Open `app.R` in RStudio.
4. Click "Run App" or run `shiny::runApp()`.


## Language

The user interface includes English labels.
Source-code comments are mainly written in English.
